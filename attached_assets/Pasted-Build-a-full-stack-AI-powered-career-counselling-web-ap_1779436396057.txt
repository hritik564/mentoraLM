Build a full-stack AI-powered career counselling web application called "MentorAlm" 
(domain: mentoralm.com). This is a production-quality MVP.

---

## TECH STACK

Frontend: React + Vite + TailwindCSS + Framer Motion
Backend: Node.js + Express
Database: PostgreSQL (use Prisma ORM)
Auth: JWT-based (access + refresh tokens), bcrypt for passwords
AI: Anthropic Claude API (claude-sonnet-4-20250514) — treat this as the AI counsellor
Payments: Razorpay integration (Indian payment gateway)
File uploads: Multer (for profile photos)
Email: Nodemailer (for booking confirmations)

---

### STUDENT DASHBOARD (authenticated)

After login, students land on their personal dashboard.

**Dashboard Layout:**
- Left sidebar: Navigation icons (Dashboard, AI Counsellor, My Services, Profile, 
  Roadmap, Settings)
- Top bar: "Hello, [Name]" + notification bell + profile avatar
- Main content area

**Dashboard Home:**
- Profile completion progress bar (percentage) — prominent, with "Complete Profile" CTA
- Quick action cards: "Chat with AI", "Browse Services", "View Roadmap", "Book Session"
- "Your AI Summary" card — short AI-generated summary of the student's profile 
  (generated from their profile data, shown once profile is >50% complete)
- Recently viewed services
- Upcoming sessions (if any booked)

**Profile Completion (Multi-step onboarding — this is CRITICAL):**

This is NOT a regular form. It's a beautiful multi-step wizard with progress indicator.
Each step is one screen. Smooth transition between steps. 
Show completion percentage. Allow saving and returning.

Step 1 — Personal Info:
- Full name, date of birth, gender, city, state, profile photo upload

Step 2 — Academic Background:
- Current education level: [Class 10, Class 11, Class 12, Undergraduate, Gap Year]
- Board: [CBSE, ICSE, IB, State Board, Other]
- School/College name
- Current grade/percentage (or expected)
- Subjects/Stream: Science (PCM/PCB), Commerce, Arts, or specific UG subjects

Step 3 — Interests & Strengths:
- Top 3 interest areas (multi-select chips):
  Technology, Medicine, Design, Law, Business, Teaching, Arts, Sports, Science, 
  Finance, Government/Civil Services, Media, Psychology, Architecture, Other
- Subjects you're strongest in (multi-select)
- Activities/hobbies (free text)
- What energizes you? (free text, 2-3 sentences)

Step 4 — Career Aspirations:
- Dream career/field (free text)
- Colleges you're targeting (multi-select or free text)
- Are you open to studying abroad? [Yes / No / Maybe]
- What's your biggest career concern right now? (free text)

Step 5 — Family & Financial Context:
- Annual family income bracket: [<3L, 3-6L, 6-12L, 12-25L, 25L+, Prefer not to say]
- Parents' education background (brief)
- Any family pressure on career choice? [Yes/No + explain if yes]
- Budget for higher education: [<5L, 5-15L, 15-30L, 30L+, Need scholarship]

Step 6 — Goals & Timeline:
- What do you want to achieve in 5 years? (free text)
- What have you already tried? (coaching classes, exams appeared, etc.)
- What's stopping you from your goal right now? (free text)
- How did you hear about MentorAlm? [Social Media, Friend, Search, Ad, Other]

After completing all steps: Show a congratulations screen + "Start Chatting with Your 
AI Counsellor" CTA.

**AI Counsellor Chat Page:**

This is the core feature. Full-screen chat interface (like a premium ChatGPT UI).

UI Requirements:
- Dark chat interface
- Student messages on right (blue bubbles), AI on left (dark card with MentorAlm logo)
- Typing indicator animation
- Each AI response can include: text + optionally a "Recommended Service" card at the 
  bottom of the response (shown when AI detects the student needs expert help)
- Message history persisted in database
- New chat button
- "Based on your profile" badge on first message to show it's personalized

AI Behaviour (System Prompt to Claude):
Construct the system prompt dynamically by injecting the student's full profile data.

System prompt structure:
"""
You are MentorAlm, an expert AI career counsellor for Indian students. You have deep 
knowledge of Indian education systems (CBSE, ICSE, IB, state boards), entrance exams 
(JEE, NEET, CLAT, CUET, CAT, UPSC, NDA, NID, CEED, etc.), top Indian colleges (IITs, 
NITs, AIIMS, NLUs, IIMs, NIFT, etc.), and career paths.

You are warm, encouraging, specific, and practical. You never give generic advice.
You always reference the student's actual profile in your responses.

Student Profile:
Name: [name]
Age/Class: [level]
Board: [board]
Stream: [stream]  
Grades: [grades]
City: [city]
Interests: [interests]
Strengths: [strengths]
Dream career: [dream_career]
Target colleges: [target_colleges]
Biggest concern: [concern]
Family budget: [budget]
5-year goal: [goal]
What's stopping them: [blockers]

Rules:
1. Always address the student by name
2. Reference their specific profile details in answers
3. Be specific — name actual exams, colleges, timelines relevant to them
4. When a question requires deep personalised mentoring or emotional support, 
   acknowledge it and say: "For this, a 1-on-1 session with our expert counsellor 
   would give you a much more in-depth answer. [Book a Session]"
5. Keep responses concise and scannable (use bullet points when listing steps)
6. Never make up statistics. If unsure, say so.
7. Maintain context within the conversation.
"""

Each conversation message is stored in DB: [userId, role, content, timestamp]
Load last 20 messages as context in each API call.

**My Services (Marketplace for student):**

Shows two tabs:
1. "Browse Services" — all published services (grid cards)
2. "My Purchases" — services the student has paid for (with status, access button)

Service Card (Browse):
- Title, short description, category tag, duration, price in INR, "Book Now" button
- If already purchased: show "Purchased" badge

Service Detail Page:
- Full description, what's included (bullet list), who it's for, counsellor bio, 
  duration, price, "Book This Session" CTA
- Reviews section (placeholder)

Booking Flow:
1. Click "Book Now" → Modal: select date/time slot (admin sets available slots)
2. Confirm details → Payment via Razorpay
3. On payment success: create booking record, send confirmation email, show in 
   "My Purchases"

**Roadmap Page:**

After profile is complete and at least 3 AI conversations have happened, show a 
generated career roadmap. 

Call Claude API to generate a structured roadmap based on the student's profile.
Display it as a visual timeline (vertical, card-based steps):
- Phase 1: Immediate (Next 3 months)
- Phase 2: Short-term (3-12 months)  
- Phase 3: Medium-term (1-3 years)
- Phase 4: Long-term (3-5 years)

Each phase: specific action items, exams to target, resources to use.
Store generated roadmap in DB. Allow "Regenerate" after profile update.

**Services Management:**
- Table of all services with: Title, Category, Price, Status (Published/Draft), Actions

  - Title
  - Short description (for card)
  - Full description (rich text / textarea)
  - What's included (add multiple bullet points)
  - Category: [Career Counselling, Interview Prep, College Admissions, Resume Review, 
    Other]

  - Counsellor name + bio

- Table: Student name, Service, Date/Time, Payment Status, Amount, Actions

**Messages/Contact:**
- View all contact form submissions

## DATABASE SCHEMA (Prisma)

Tables needed:
- User (id, name, email, phone, passwordHash, role[STUDENT/ADMIN], createdAt)
- StudentProfile (id, userId, all profile fields from steps 1-6, completionPercent)
- Service (id, title, shortDesc, fullDesc, included[], category, duration, price, 
  counsellorName, counsellorBio, thumbnailUrl, status[DRAFT/PUBLISHED], slots[], 
  createdAt)
- Booking (id, userId, serviceId, slotDateTime, paymentStatus, razorpayOrderId, 
  amount, status[UPCOMING/COMPLETED/CANCELLED], createdAt)
- ChatMessage (id, userId, role[USER/ASSISTANT], content, createdAt)
- Roadmap (id, userId, content, generatedAt)
- ContactMessage (id, name, email, message, createdAt)

## ADDITIONAL REQUIREMENTS

1. All API routes protected by JWT middleware except public routes
2. Rate limiting on AI chat endpoint (max 20 messages per day for free users)
3. Mobile responsive — the entire app must work on mobile
4. Loading skeletons for all async data fetches
5. Toast notifications for all actions (success/error)
6. 404 and error pages styled to match the design system
7. SEO meta tags on all public pages
8. Smooth page transitions using Framer Motion
9. The AI chat must stream responses (use Anthropic streaming API) for better UX
