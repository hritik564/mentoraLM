## 1. SLOTS FIELD — PROPER UI

Replace the raw JSON [] input in the Edit/Add Service form with a proper UI:

- Add an "Add Time Slot" button that opens a date picker + time picker

- Each added slot shows as a removable chip/tag (e.g. "23 May, 11:00 AM ×")

## 2. REVENUE CALCULATION

Fix the Total Revenue stat on the admin dashboard:

- Count revenue from ALL bookings where status = 'COMPLETED' 

  OR payment_status = 'paid'

- Currently only counting payment_status = 'paid' which is always 0 

  in mock/Razorpay test mode

- Check if the same userId already has a booking for the same serviceId

- If duplicate found, return a 400 error with message: 

  "You already have an active booking for this session."

- Show this message as a toast notification on the student's screen
